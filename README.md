# BatchNwcExport — пакетный экспорт Revit → Navisworks (.nwc) из заданного 3D-вида

Два варианта в одном комплекте:

| | Плагин (C#) | Скрипт для Revit Batch Processor |
|---|---|---|
| Запуск | Кнопка на ленте Revit | Планировщик Windows, ночью |
| Участие человека | Нажать кнопку, дождаться | Не нужно |
| Файлы | `*.cs`, `.csproj`, `.addin` | `rbp/export_nwc_rbp.py` |

## Как работает

Для каждой модели из списка:
1. Если модель уже открыта в Revit — берётся она; иначе открывается **с отсоединением от ФХ** (центральная не блокируется) и со всеми рабочими наборами.
2. Ищется 3D-вид по имени (можно несколько через `;`, например `Navisworks;NWC;3D_Навис` — берётся первый найденный).
3. Экспорт в NWC **только того, что видно на этом виде** (`ExportScope = View`) — фильтры, скрытые элементы и рабочие наборы вида учитываются.
4. Модель закрывается без сохранения.
5. В папке вывода пишется лог `nwc_export_log_*.csv` (открывается в Excel).

Предупреждения и типовые диалоги (неразрешённые ссылки, отсутствующие апдейтеры) гасятся автоматически только на время пакетного экспорта.

## Требования

- Revit 2021–2027
- **Navisworks NWC Export Utility** той же версии, что и Revit (ставится с Navisworks или отдельно с сайта Autodesk). Плагин проверяет это при запуске.

## Сборка и установка плагина

```bat
:: Revit 2025+ (.NET 8)
dotnet build -c Release -f net8.0-windows -p:RevitVersion=2025

:: Revit 2021–2024 (.NET Framework 4.8)
dotnet build -c Release -f net48 -p:RevitVersion=2024
```

1. Скопировать `BatchNwcExport.dll` в `C:\BIMTools\BatchNwcExport\` (или поправить путь в `.addin`).
2. Скопировать `BatchNwcExport.addin` в `%AppData%\Autodesk\Revit\Addins\<версия>\`.
3. Перезапустить Revit → вкладка **BIM Tools → Пакетный экспорт NWC**.

Настройки запоминаются в `%AppData%\BatchNwcExport\settings.json`.

## Ночной запуск без человека (Revit Batch Processor)

1. Установить [Revit Batch Processor](https://github.com/bvn-architecture/RevitBatchProcessor) (бесплатный).
2. В `rbp/export_nwc_rbp.py` поправить блок НАСТРОЙКИ (имена видов, сетевая папка).
3. В GUI RBP: указать скрипт, список моделей (.txt), версию Revit, опции **Detach from central** и **Open all worksets**; сохранить настройки в json.
4. Планировщик заданий Windows:
   `BatchRvt.exe --settings_file "C:\BIMTools\rbp_nwc_settings.json"`

## Рекомендации для отдела

- Завести в шаблоне проекта один стандартный вид, например **`Navisworks`**, с шаблоном вида: без аннотаций, без помещений/зон, без временно скрытых элементов, детализация «Высокая». Тогда один и тот же список видов работает для всех разделов (АР, КР, ОВ, ВК…).
- Суффикс `_{date}` даёт версионирование: `Корпус1_КР_20260930.nwc`. Без суффикса файлы перезаписываются — удобно, если сводная модель NWF ссылается на постоянные имена.
- Облачные модели (ACC/BIM 360) этим способом не открываются — только файлы на диске/сервере.
